# ScreenTale Releases

Official signed and notarized ScreenTale downloads for Apple Silicon Macs.

- Download installers from [Releases](https://github.com/thienanblog/screentale-releases/releases).
- Existing Swift installations migrate through the signed [Sparkle appcast](https://thienanblog.github.io/screentale-releases/appcast.xml).
- ScreenTale 1.0 and later use the signed [Tauri update feed](https://thienanblog.github.io/screentale-releases/tauri/stable.json).
- Purchase and trial access are managed through the ScreenTale app and Polar.

This repository intentionally contains public release artifacts and update metadata only. It does not contain the private ScreenTale source code. Never post license keys or customer information in public issues.
